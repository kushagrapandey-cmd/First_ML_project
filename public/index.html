CURIOUS ABOUT THE DETAILS?

Less mystery.
More intention.

YTGuide is a focused learning workspace with an explainable recommendation engine. No endless feed. No made-up AI promises.

01

Start with your question

Select a subject and add a goal. We compare that query directly with each candidate’s text, instead of using the first video as a substitute for your interests.

02

See why it was chosen

A Python TF-IDF model weights terms by how distinctive they are. Cosine similarity measures text overlap; a channel diversity adjustment reduces repeated educators in the shortlist.

03

Make learning the point

Watch in a focused player, set a study timer, take notes, and mark lessons complete. Your workspace stays on your device, without an account.

What this can—and can’t—promise

Relevance isn’t teaching quality. There is no reliable “best five on YouTube” guarantee. This is a content-based information retrieval system, not a neural model trained to judge pedagogy.

Two honest sources. Catalogue mode uses a maintained set of lessons. Live mode requires a server-side YouTube Data API key and retrieves current candidates. Failures fall back to the catalogue with a visible notice. Language filters may return fewer than five lessons.

A calmer page, not a browser blocker. YTGuide removes our own feed, comments, and autoplay. YouTube controls its player, ads, branding, and related suggestions; we don’t hide or override those controls.

A workshop idea, developed further. The original college project used bag-of-words similarity over a collected dataset. Creating a dataset was a valid first experiment; duplicate data, stale candidates, and absent evaluation were the weaknesses to address.
