CURIOUS ABOUT THE DETAILS?

Less mystery.
More intention.

YTGuide is a focused learning workspace with an explainable recommendation engine. No endless feed. Meaning-aware recommendations, with clear limits.

01

Start with your question

Select a subject and add a goal. We compare that query directly with each candidate’s text, instead of using the first video as a substitute for your interests.

02

See why it was chosen

A pretrained multilingual sentence model compares the meaning of your question with lesson metadata. Keyword relevance and educator diversity also contribute. The source notice tells you if keyword fallback is used.

03

Make learning the point

Watch in a focused player, set a study timer, take notes, and mark lessons complete. Sign in to save your activity and sync it across devices.

What this can—and can’t—promise

Relevance isn’t teaching quality. There is no reliable “best five on YouTube” guarantee. The neural model estimates semantic relevance. It was not trained by us to judge teaching quality, and it does not watch or understand the full video.

Two honest sources. Catalogue mode uses a maintained set of lessons. Live mode requires a server-side YouTube Data API key and retrieves current candidates. Unavailable live searches show a clear error rather than unrelated lessons. Language filters may return fewer than five lessons.

A calmer page, not a browser blocker. YTGuide removes our own feed, comments, and autoplay. YouTube controls its player, ads, branding, and related suggestions; we don’t hide or override those controls.

A workshop idea, developed further. The original college project used bag-of-words similarity over a collected dataset. Creating a dataset was a valid first experiment; duplicate data, stale candidates, and absent evaluation were the weaknesses to address.
